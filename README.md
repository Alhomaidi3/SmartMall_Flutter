# 📱 Smart Mall Guide — Mobile Application

A cross-platform mobile application built with Flutter and Dart to provide mall visitors with a smart indoor navigation and store exploration experience.

The application helps users discover stores, categories, and facilities within large shopping centers through interactive indoor maps, smart search, real-time data integration, and personalized features.

## 🏗️ Architecture

The application follows Clean Architecture principles to provide a maintainable, scalable, and testable codebase with clear separation of concerns.

Directory / File	Description

core/	Core configurations and API endpoints

models/	Data models and JSON serialization

services/	API communication and secure storage

screens/	Application screens and features

widgets/	Reusable UI components

## 🔑 Key Features
## 🎨 Clean Architecture

Separation of application layers and responsibilities.

Centralized API endpoint management.

Strongly typed Dart models with fromJson() and toJson().

Reusable UI components and widgets.

Centralized network and error handling.

Secure local session management.

## 🗺️ Indoor Navigation

Interactive indoor mall maps.

Support for multiple mall floors and sections.

Store location visualization.

Interactive route guidance to selected stores.

## 🌐 Localization & Themes

Full support for Arabic and English.

Automatic RTL/LTR layout switching.

Light and Dark theme support.

Consistent and responsive user interface.

## 👤 User Features

User registration and secure login.

Guest browsing mode.

Smart store search and filtering.

Store categories and floor-based browsing.

Store details and operating hours.

Store ratings and reviews.

Favorite stores management.

## 🛡️ Admin Features

Authorized administrators can manage the mall's content directly through the application, including:

Store management.

Category management.

User management.

Create, read, update, and delete (CRUD) operations.

Store information and location management.

## 🔐 Security

The application implements several security mechanisms:

JWT Authentication for secure API communication.

FlutterSecureStorage for protected local token storage.

Role-based access control for authorized admin functionality.

Secure communication with the backend REST API.
